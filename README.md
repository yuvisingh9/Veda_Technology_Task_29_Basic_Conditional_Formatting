# Task 29 – Basic Conditional Formatting

## Project Overview
This project demonstrates Basic Conditional Formatting in Microsoft Excel using a Retail Sales dataset.

## Objectives
- Highlight the top 10 values automatically.
- Highlight the bottom 10 values automatically.
- Improve report readability.
- Use conditional formatting rules instead of manual colours.

## Tools Used
- Microsoft Excel

## Workbook Contents
1. Summary
2. Retail Sales
3. Rules List
4. Mini Guide

## Conditional Formatting Rules
- Top 10 Sales – Green
- Bottom 10 Sales – Red
- Top 10 Profit – Green
- Bottom 10 Profit – Red
- Units Sold – Red to Yellow to Green colour scale

## Key Learning
Learned how to apply automatic conditional formatting rules, improve data presentation, and test edge cases.

## Deliverables
- Formatted Excel workbook
- Conditional formatting rules list
- Mini guide and edge-case tests
